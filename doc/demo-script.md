# 시연 영상 순서 (약 3~4분)

Production(https://bidradar-web-mocha.vercel.app)에서 녹화한다. 화면 녹화는 Windows `Win + Alt + R`(Xbox Game Bar) 또는 OBS를 쓴다.

## 녹화 전 준비
- [ ] **시연용 Google 계정**으로 로그인해 둔다 (본인 계정이면 이메일이 화면에 보이지 않게 주의)
- [ ] 시연용 계정의 회사 프로필을 수집 공고와 잘 맞게 저장해 둔다
  - 예: 업종 `토목설계`, `건설사업관리` / 지역 `전남`, `광주`, `경기` / 관심 키워드 `설계`, `감리`, `정밀안전진단` / 금액 상한 30억
- [ ] 추천 화면을 한 번 열어 평가를 미리 받아 둔다 (첫 조회는 최대 약 30초)
- [ ] 브라우저 확대 125%, 북마크바·알림 끄기

## 주의
- 채팅 응답은 보통 6~15초 걸린다. 녹화 후 대기 구간은 편집으로 줄여도 된다.
- "지금 수집"은 60초 간격 제한이 있다. 리허설 직후 바로 누르면 남은 초가 표시된다.
- 탈퇴 버튼은 시연에서 **누르지 않는다** (계정 삭제).
- 녹화한 영상은 YouTube(일부 공개) 등에 올리고 README "시연 영상" 링크에 넣는다.
