## 1. 개요
| 항목 | 내용 |
|---|---|
| 목표 | 실제 사용자가 공고를 찾고, 이해하고, 프로필을 저장하고, AI 검색·맞춤 추천을 쓰는 과정에서 막히는 지점을 찾는다 |

## 3. 테스트 시나리오
테스터에게 아래 순서를 안내한다. 각 단계의 "확인할 점"은 진행자가 결과를 정리할 때 쓴다.

| 단계 | 테스터에게 안내할 내용 | 확인할 점 |
|---|---|---|
| 1. 로그인 | 오른쪽 위 로그인 버튼으로 Google 로그인 | 로그인 후 서비스로 돌아오는가, 오류나 경고 화면이 없는가 |
| 2. 프로필 | 회사 프로필(업종, 지역, 금액 범위, 관심 키워드)을 입력하고 개인정보 동의 후 저장 | 동의 문구가 이해되는가, 저장 후 다시 열면 값이 남아 있는가 |
| 3. 목록·필터 | 입찰공고 목록에서 업무 구분·키워드·금액·마감일로 관심 공고 찾기 | 원하는 공고를 찾을 수 있는가, 필터 사용이 어렵지 않은가 |
| 4. AI 검색 채팅 | 상단 "AI 검색"에서 원하는 조건을 문장으로 물어보기 (예: "서울 SW 개발 1억 이하, 이번 주 마감 공고 찾아줘" 또는 예시 질문 버튼). 답변을 받으면 "그중에서 금액이 가장 큰 공고는?"처럼 **이어서 한 번 더** 질문 | 답변과 근거 공고 카드가 질문에 맞는가, 이어지는 질문에서 앞 대화를 기억하는가, 기다리는 시간(보통 10초 안팎)이 견딜 만한가, "AI 생성" 표시를 알아보는가 |
| 5. 맞춤 추천·👍/👎 | 상단 "추천"에서 프로필 기준 추천 목록 보기 (처음엔 최대 30초). 마음에 드는 공고에 👍, 맞지 않는 공고에 👎를 한 번 이상 누르기. "더 불러오기"가 보이면 눌러 보기 | 점수와 근거가 프로필과 맞다고 느끼는가, 👍/👎를 누르는 이유(다음 평가에 반영)를 이해하는가, 첫 조회 대기 시간이 견딜 만한가 |
| 6. 상세 | 공고 하나를 열어 AI 요약과 참가자격 확인, 나라장터 원문 열기 | 요약이 이해에 도움이 되는가, "AI 생성"·참고용 표시를 알아보는가 |
| 7. 지금 수집 | 수집 설정 화면에서 업무 구분·건수는 **바꾸거나 저장하지 말고** "지금 수집"만 누르고 결과 확인 (다른 사람이 이미 눌렀다면 남은 초가 표시됨) | 기다리는 동안 진행 중임을 알 수 있는가, 결과(받은·새로 저장한 건수)를 이해하는가 |
| 8. 피드백 | "의견 보내기"로 만족도(1~5)와 의견 남기기 | 제출 완료 메시지가 보이는가 |

- 4·5단계는 로그인이 필요하다. 2단계에서 프로필을 저장하지 않았으면 5단계에서 "프로필을 먼저 작성해 주세요" 안내가 나오는지도 함께 확인한다 (화면 확인이 안 된 부분).
- 휴대폰에서는 상단 메뉴가 넘치면 메뉴 영역을 가로로 밀어 "추천"·"수집 설정"을 찾을 수 있다고 안내한다.
- 테스터가 막히면 바로 도와주지 말고, 어디서 왜 막혔는지 먼저 기록한 뒤 안내한다.

### 테스트 후 질문 (피드백 폼 의견란에 함께 적도록 안내)
1. 가장 유용했던 기능은?
2. 가장 불편했거나 헷갈렸던 화면은?
3. 실제 업무에 쓴다면 꼭 있었으면 하는 기능은?

## 4. 결과 정리
- 서비스 피드백 폼의 응답은 Supabase `feedbacks` 테이블에 저장된다 (만족도, 의견, 제출 화면, 로그인한 경우 사용자).
- 진행자 관찰 내용과 폼 응답을 아래 표로 합쳐 정리한다. 테스터는 개인정보 대신 `T1`, `T2`처럼 표기한다.

### 테스트 진행 (2026-10-19, Production)
- 테스트 시간 12:55~13:17 UTC(21:55~22:17 KST). 테스터 번호는 계정 생성 순서이며(T0은 운영 계정), 이메일 등 개인정보는 적지 않는다.
- **결과는 서버 기록으로 확인한 것만 적었다**: Supabase(`profiles`·`recommendations`·`collect_runs`·`feedbacks`)와 Vercel api 로그(요청마다 사용자 ID가 찍히는 프로필·추천·Agent 조회). Vercel Hobby는 api 로그를 1시간만 보관하므로 테스트 직후 대조해 기록했다.
- 목록·필터(3단계)와 상세(6단계)는 로그인 없이도 되는 조회라 테스터별로 구분할 수 없어 표에 넣지 않았다. 진행자 확인 결과 테스터 기기는 모두 **PC**이고, 직군·소요 시간은 확인하지 못했다.
- **탈퇴·비로그인 의견을 감안한 점**
  - 탈퇴하면 그 계정의 프로필·추천(👍/👎 포함)은 삭제되고, 피드백·수집 기록의 작성자는 비워진다(계약서 v1.1). 그래서 탈퇴한 계정의 활동은 DB에 남지 않아 **api 로그로 확인**했다.
  - 작성자가 비어 있는 의견 1건은 "로그인 없이 제출" 또는 "제출 후 탈퇴" 중 하나다. 이 의견은 탈퇴(13:15:36) **74초 뒤**(13:16:50) 홈(`/`)에서 제출되었으므로 "제출 후 탈퇴"는 아니고, 탈퇴한 T5가 탈퇴 직후 남긴 것으로 **추정**한다(내용도 가입·탈퇴에 관한 것). 다만 로그인하지 않은 다른 사람이 남겼을 가능성은 배제할 수 없다.
- Vercel api 로그에 테스트 시간 동안 오류(error) 수준 로그 **0건**.
